# Coding conventions

Follow existing patterns so a change looks like it was written by the team — not like it
was generated by an outside AI. The goal is consistency with the 130 000+ lines already here.

## Standing rules

- **Reuse before you add.** Check whether something already exists (a service, a DAO, a
  directive) before creating it. 129 resource files exist in `service/resources/` alone.
- **Do not silently simplify.** Implement what the ticket asks; surface any simplification
  as a decision rather than acting on it unilaterally.
- **Stay in scope.** No extra unrequested machinery "while you're in there."
- **English code, Slovak text.** All identifiers, keys, and code in English. Slovak appears
  **only** in translation values (`app/scripts.no.min/langs/{sk,en}.js`) and in existing
  in-code comments — do not add new Slovak-language identifiers.
- **Short comments.** One concise line stating intent — no multi-line explanatory blocks,
  no restating the code. Trim Javadoc to one line for simple methods.

## JavaScript (client — AngularJS 1.5, ES5)

**Formatter / linter:** JSHint (`publicERANET-client/.jshintrc`). Run `grunt test` to check.
Key rules in force: `camelcase`, `curly`, `eqeqeq`, `quotmark: single`, `strict`, `undef`,
`unused`, `latedef`, `trailing`.

**EditorConfig:** indent with **tabs** (size 4), LF line endings, UTF-8, single quotes.

### Naming

- Files: `camelCase.js`
- Controller classes: `PascalCaseController` (e.g., `CompanyProfileController`)
- Factories (resources): `EntityNameResource` for `$resource` wrapper, `EntityName` for business wrapper
- Factories (services): `PascalCase` (e.g., `Alerts`, `Utils`, `Procurements`)
- Directives: `camelCase` matching the HTML element/attribute name
- Filters: `camelCaseFilter` suffix
- Constants: `SCREAMING_SNAKE_CASE`

### Controller pattern

```javascript
'use strict';

angular.module('controllers')
    .controller('ExampleController', ['$scope', 'SomeService',
        function define($scope, SomeService) {
            // body
        }]);
```

- Array DI annotation always — never rely on minification-unsafe implicit DI.
- Constructor function parameter named `define` (not the controller name).
- Use `$rootScope` for cross-controller shared state (`currentProcurement`, `currentUser`, etc.).

### Service/factory pattern

```javascript
'use strict';
angular.module('services').factory('ExampleService', ['$rootScope',
    function ExampleService($rootScope) {
        var privateVar = {};

        var privateHelper = function (x) { /* ... */ };

        var serviceResult = {};

        serviceResult.publicMethod = function (params, callback) { /* ... */ };

        return serviceResult;
    }
]);
```

- Private state in `var` at top; private helpers as `var fn = function() {}`.
- Public API on `var serviceResult = {}` returned at end.
- Callbacks (not Promises) for async calls; callback functions named `afterLoad`, `afterSave`, etc.

### REST resource pattern

```javascript
// Part 1 — $resource factory (in service/resources/)
angular.module('services').factory('ExampleResource', ['$resource',
    function ExampleResource($resource) {
        return $resource('webresources/sc/example/:id', { id: '@id' }, {
            query: { method: 'POST', url: 'webresources/sc/example/query' }
        });
    }
]);
// Part 2 — business factory wrapping the resource
```

All REST URLs start with `webresources/sc/`.

### Error handling (client)

- HTTP errors handled centrally by `mainInterceptor.js` — do not duplicate.
- Business errors via `Alerts.error()` / `Alerts.longError()` from `alerts.js`.

### ui-select gotcha

- To clear a `ui-select` back to empty, set the model to `undefined` — `null` does **not**
  clear the selection, even when the empty option's id is `null`. (EP-13137 AC#8 reset.)

### fire-and-forget reload gotcha

- When a UI refresh depends on data a **fire-and-forget** notification/side-effect endpoint
  writes server-side, trigger the reload **inside that call's success callback**, not in
  parallel — otherwise the reload GET races the write and shows stale data until the next refresh.

## Java (server — Java 8 / Java EE 7)

**Build:** Maven (`mvn clean package`) **on JDK 8** — the default Maven here runs under JDK 21,
which crashes the EclipseLink static weaver and the `dependency:tree` mojo; point `JAVA_HOME`
at JDK 8 (e.g. `jdk1.8.0_351`). Base package: `sk.innovis.eranetpublic.server`.

### Naming

- Entities: `PascalCase`, no suffix (e.g., `Procurement`, `Addendum`)
- DAOs: entity name + `Dao` (e.g., `ProcurementDao`)
- Services: entity name + `Service` (e.g., `ProcurementService`)
- Interfaces: `Has` prefix + capability (e.g., `HasId`, `HasAttachment`)
- Constants: `SCREAMING_SNAKE_CASE` as `static final` fields

### Service pattern

```java
@Path("sc/example")
@Produces(MediaType.APPLICATION_JSON)
@Consumes(MediaType.APPLICATION_JSON)
@Stateless
@RolesAllowed(SystemUserGroup.ROLE_NAME_USER)
public class ExampleService extends BaseService<ExampleEntity> {

    @EJB
    private ExampleDao exampleDao;

    @GET
    @Path("{id}")
    public ExampleEntity getExample(@PathParam("id") Integer id) {
        return exampleDao.find(id);
    }
}
```

- Always extend `BaseService<T>` — gives logger, date formats, and service-layer pattern.
- Inject DAOs via `@EJB`, not `@Inject`, for EJB proxying.
- **Never call DAO methods directly from a controller/endpoint without going through BaseService** — use a `BaseService` method when one exists.
- Register each new service in `ApplicationConfig.java`'s `getClasses()`.

### DAO pattern

```java
@Stateless
public class ExampleDao extends BaseDao<ExampleEntity> {
    // entity-specific query methods only
}
```

- Extend `BaseDao<T>` — gives `EntityManager`, `create`, `find`, `update`, `delete`.
- Never inject `EntityManager` directly in a service — use a DAO.

### Entity pattern

```java
@Entity
@Table(name = "example")
@XmlRootElement
public class ExampleEntity implements Serializable, HasId {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Integer id;
    // ...
}
```

- `@Transient` for computed fields not persisted to DB.
- Lombok `@Data` / `@Getter` / `@Setter` acceptable for new or helper classes.

### Error handling (server)

- Business rule violations → `WebApplicationException` with appropriate `Response.Status`.
- `AccessLocalException` already maps to HTTP 403 via `AccessLocalExceptionHandler`.
- Use `logger.warn()` when forbidden operations are attempted.

### Logging (server)

- Logger injected: `@Inject protected Logger logger;` (inherited from `BaseService`).
- Pattern: `logger.debug("Loading entity {}", entity.getId())`.
- No `System.out.println` or stray `console.log` in committed code.

## Database / Liquibase

- **Schema changes** (CREATE TABLE, ALTER TABLE, etc.) → Liquibase changeset in `publicERANET-server/src/main/sql/`.
- **Data inserts** → raw SQL scripts only.
- Changeset author: **`m.bijalko`** always.
- Apply migrations with `configS.bat` before starting WildFly.
- When backfilling a JPA enum stored as **ordinal** via raw SQL, keep the literal ints aligned
  with the enum's declaration order, and never reorder persisted enum constants.
